# shayneptorres.github.io

Personal portfolio for Shayne Torres, served by GitHub Pages.

Plain HTML + `style.css`, no build step. Edit and push to `main`; Pages redeploys in about a minute.

- `index.html` — the page
- `style.css` — styles (light and dark mode)
- `assets/` — portrait and app icons
- `Shayne_Torres_Resume.pdf` — linked from the Resume button; replace it when the resume changes
